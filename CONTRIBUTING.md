# Contributing

Much appreciation for your interest in this project.

This repository was developed as part of an MSc Data Science dissertation. While the project is not under active development, suggestions, bug reports, and improvements are welcome.

## How to Contribute
1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Submit a pull request with a clear description of your improvements.

Please ensure your code is well documented and follows Python best practices. 
Thank you once again
